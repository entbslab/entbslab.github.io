## 3. 운영 방식 비교

### 3-1. 연간 비용 (연간 결제 기준, 부가세 별도)
| 방식 | 플랫폼 비용 | 도메인 | 합계(대략) |
|---|---|---|---|
| A. Wix Light | $17/월 = $204/년 | 첫해 무료 쿠폰, 이후 약 ₩24,000/년 | 약 ₩30만/년 |
| B. vibeX Pro | $375/년 + 크레딧 추가구매 | 별도 구매 | 약 ₩55만/년 이상 |
| C. 정적 사이트 + 무료 호스팅 | ₩0 | .com 약 $10~11/년 (Cloudflare) 또는 약 ₩24,000/년 (가비아) | 약 ₩1.5~3만/년 |

### 3-2. 관리 편의성
| 방식 | 비개발자 수정 | 장기 리스크 |
|---|---|---|
| A. Wix | 드래그앤드롭, 블로그 게시판 내장. 학부 내 레퍼런스 있음 | 플랫폼 락인, 매년 결제 담당자 필요, 결제 끊기면 사이트 다운 |
| B. vibeX | 프롬프트로 수정. 결과 예측이 어렵고 크레딧 소모 | 스타트업 존속 리스크, 코드 이관 어려움 |
| C. 정적 + Git CMS | 웹 관리자 화면(/admin)에서 공지·연구진·성과를 폼으로 입력. 계정은 GitHub 로그인 | 결제 의존 없음. 코드·콘텐츠가 저장소에 남아 담당자 바뀌어도 인수인계 가능 |

### 3-3. 권장안: C. 프론트엔드 전용(정적 사이트) + Git 기반 CMS
프론트엔드만으로 구축 가능한가에 대한 답은 "가능"이다. 공지·연구진·성과 같은 콘텐츠를 저장소의 마크다운/JSON 파일로 두고, 빌드 시 HTML로 만들어 CDN에 올리면 서버·DB 없이 운영된다. 관리자는 웹 화면에서 편집하고, 저장하면 자동으로 재배포된다.

**구성**
- 사이트 생성기: Astro (콘텐츠 컬렉션으로 공지/연구진/성과를 타입별 관리, 빌드 결과는 순수 HTML)
- 관리 화면: Decap CMS 또는 Sveltia CMS (오픈소스, 무료, `/admin`에서 폼 편집, 이미지 업로드 포함)
- 저장소: GitHub (조직 계정 권장: 예 `ku-cesm`), 관리 담당자를 collaborator로 추가
- 호스팅: Cloudflare Pages (무료, 대역폭 무제한, SSL 자동) — 대안 GitHub Pages / Netlify
- 로그인: CMS의 GitHub OAuth용 Cloudflare Worker 1개 (무료 구간, 한 번 설정)
- 도메인: Cloudflare Registrar에서 .com 등록(원가 판매) 또는 가비아(국내 결제·세금계산서 필요 시). `.kr`도 가비아에서 가능

**관리자 워크플로우 (조교 기준)**
1. `사이트주소/admin` 접속 → GitHub 로그인
2. "공지사항 > 새 글" → 제목·날짜·본문·첨부 입력 → 저장(Publish)
3. 1~2분 내 자동 빌드·배포 완료

**도메인 후보 (가용 여부 확인 필요)**
- ku-cesm.com / cesm-ku.com / entbiz.kr / entbiz-ku.com
- 학교 서브도메인(`*.korea.ac.kr`)은 정보전산처 신청 절차가 있어 별도 검토

**Wix를 택할 경우의 조건**: 학부 내 레퍼런스가 있고 조교가 이미 익숙하다면 Wix Light도 합리적. 단, 매년 약 30만원 결제 주체(센터 운영비)를 정해야 한다.

## 4. 목업 사이트 설계

### 4-1. 정보 구조 (icic 메뉴 규모 + Wix 연구실 스타일)
```
HOME
ABOUT      ├ 센터 소개 (비전·목적, 활동분야)
           ├ 센터장 인사말
           └ 연구진 (센터장 / 공동연구원 / Research Fellow)
RESEARCH   ├ 연구 프로젝트
           ├ 논문·출판
           └ 세미나·포럼
NEWS       ├ 공지사항
           ├ 센터 소식 (언론·행사)
           └ 자료실
CONTACT      위치·연락처
```
- 1차는 국문 기본, 메뉴 라벨은 영문(참고 사이트 관례). 영문 페이지는 2차.
- 공지·소식·자료실·연구진·성과는 CMS 컬렉션. 소개·인사말·연락처는 단일 페이지.

### 4-3. 디자인 방향
- 톤: 고려대 크림슨(#8B0029 계열) 포인트 + 흰 배경 + 짙은 회색 텍스트. 미니멀, 여백 중심
- 서체: Pretendard(국문) + Inter(영문)
- 반응형: 모바일 우선, 햄버거 메뉴
- 이미지: 초기에는 플레이스홀더, 실제 사진은 교수님 제공

## 7. 교수님께 결정 요청할 사항
1. 운영 방식: 권장안 C(정적+무료 호스팅, 연 도메인비만) vs Wix(연 약 30만원, 학부 레퍼런스)
2. 도메인명 후보 우선순위 및 결제 주체(센터 운영비 vs 개인)
3. 관리 담당자(조교) 지정. C안이면 GitHub 계정 필요
4. 센터장 인사말 원고, 연구진 사진 및 게시 동의
5. 영문 페이지 필요 여부(1차 제외 권장)
